# Legacy Hub pilot — journey map (50k)

Snapshot prepared 2026-09-26 for [Portfolio #5014](https://github.com/jjones447/ai-coordination-bridge/issues/5014). **Status is scoped to the cited evidence, not an assertion that a later deployment is unchanged.** Cloudflare Pages deployments have been manual; merging to `main` does not publish the site. A separate current deployment readback is required before go-live or board promotion.

The environment axis is **Local/CI**, **Staging**, and **Production**. ✅ means the capability and environment scope named in that row has a runtime receipt; 🔵 means merged/tested code or an earlier environment receipt exists but activation in that cell is unverified or deliberately held; ⬜ means target or insufficient implementation evidence. A local 🔵 is *built*, not *live*. A protected endpoint's 403 is evidence for an access guard, not for the workflow behind it. Links beside each row are its evidence and 1k road.

## Delivery road

1. **Built versus activated.** Keep code and test evidence separate from current Pages deployment, D1 binding, Access, provider secret and runtime receipts. The [2026-09-22 receipt](https://github.com/jjones447/legacy-hub-pilot/issues/83#issuecomment-5780104909) explicitly says CR-1–4 were live on staging while production served an older revision.
2. **Complete the technical seams.** Verify current R2 state, then the [Drive→R2 chain](https://github.com/jjones447/fleet-work/issues/139); obtain current exact-head review for draft MEDIA binding #82. Verify webhook secret/wiring and staff workflows separately. Follow the [backup/account migration road](areas/backup-infrastructure.md) without mistaking a scratch drill for production readiness.
3. **Attended verification.** Stage and inspect each activated slice, then request the distinct production go. Preserve the six client-owned decisions in [change request #83](https://github.com/jjones447/legacy-hub-pilot/issues/83); do not infer publication approval from merged code or staging.

The [index](README.md) links each sketched 1k road. No completion percentage is assigned from this first map; Portfolio can derive one only after the row scopes and current runtime evidence are reviewed.
